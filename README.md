# St. Thomas Hospital e.V. Webpage

### Development Website

The development page can be found [here](https://thomas-hospital-e-v.github.io/)

Final deployment: https://www.thomas-hospital.de

### Local Build

```
bundle install
bundle exec jekyll serve
```


### Deployment

Pushing to `main` builds and deploys the site via GitHub Actions (`.github/workflows/pages.yml`).
Requires Settings → Pages → Source: GitHub Actions.
